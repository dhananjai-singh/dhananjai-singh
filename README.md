#### 👁️ [Diabetic Retinopathy Detection](https://github.com/dhananjai-singh/Diabetic-Retinopathy-Detection)

Deep learning that grades diabetic retinopathy (stages 0 to 4) from retinal fundus images, one of the leading causes of preventable blindness.

- ResNet-50 transfer learning plus a custom CNN, trained on APTOS 2019
- Focal loss and class weighting for heavy class imbalance
- **Grad-CAM heatmaps** show *where* the model is looking
- Gradio demo + Next.js clinical dashboard

`PyTorch` `OpenCV` `Grad-CAM` `Next.js`

#### 🚶 [Counterswing](https://github.com/dhananjai-singh/Counterswing)

A wearable that measures **arm–leg coordination while walking**. Reduced or out-of-phase arm swing is an early marker in several gait disorders.

- Smart insole (heel strike) + wrist IMU (arm swing), linked over ESP-NOW
- Per-stride phase φ and an **Arm–Leg Coordination Index (ALCI)**
- Random Forest that runs **on the phone**
- Flutter Android app: live verdict, walk history, CSV export

`ESP32` `Flutter` `scikit-learn` `BLE`
